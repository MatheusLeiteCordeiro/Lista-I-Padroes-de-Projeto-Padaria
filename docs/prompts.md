# Registro de uso de IA — Questão 3

## Prompt inicial
""Apenas mandei o enunciado da questão, visto que as orientações já foram dadas no primeiro prompt da primeira questão"

## Plano recebido
1. Criar decorador abstrato.
2. Criar decoradores concretos (MultiLayered, Sprinkles, Saying).
3. Criar novo tipo StrawberryCake.
4. Alterar Main.
5. Testar.

## Ajustes manuais previstos
- Ordem dos decoradores no último pedido.
- StrawberryCake custa 20, não 10.
- Multi-layered prefixa, não sufixa.
- Saying não altera o custo.
- Adicionar novo bolo ou decorador não pode alterar código existente.
- Formato de impressão da Order precisa bater com o enunciado.
